This project is to create a backend service for CRM web application

As part of this project, 5 API endpoints will be created in the backend. They are listed below:

  1. /customers/{id} - Uses GET HTTP method that gets details of a single customer
  2. /customers - Uses GET HTTP method that gets details of all the customers
  3. /customers - Uses POST HTTP method that creates a new user
  4. /customers/{id} - Uses PUT HTTP method that updates the customer detail
  5. /customers/{id} - Uses DELETE HTTP method that removes the customer detail
